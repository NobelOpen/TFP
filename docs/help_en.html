TaskFlow Help

v1.0

Overview

TaskFlow is a visual task automation tool that lets you build automation workflows by dragging and configuring task cards. Each task card represents a single operation step, executed in sequence from top to bottom.

Core Concepts

Flow: An ordered sequence of task cards executed from top to bottom. You can create multiple flows and switch between them using the tab bar on the left.

Task Card: Represents a specific operation. Right-click on the canvas to add a task card; double-click or right-click to edit its properties.

Variable: Data is passed between tasks via variables. To reference another card's output in a property field, use the #{card number} syntax.

Expression: Some properties support expressions using the {{expression}} syntax, e.g. {{#1.x + 10}}.

Output Reference Syntax

Subsequent cards can reference the outputs of preceding cards using the following syntax (N is the card number):

#N.image Image · #N.text Text · #N.x / #N.y Coordinates · #N.result Boolean result · #N.loopIndex Loop index

Interface Guide

Main Toolbar

The toolbar at the top of the main window contains all the core control functions of the application:

📄 New / 📂 Open / 💾 Save / 📝 Save As
Manage project files (.json). Contains all flows, cards, local variables, and UI layout states.
👁‍🗨 Hide Main Window
Click to completely hide the software's main window, bringing up a compact Real-time Task Overlay Window. How to Restore: You can also look for the TaskFlow icon in the System Tray (bottom-right of the Windows taskbar) and double-click it to show the main window again.
🪟 Real-time Task Overlay
A mini floating card that appears after hiding the main window. This overlay is always on top, making it perfect for monitoring task progress while AFK:
• Controls: Quickly switch flows (↻), run current flow (▶), run all flows (▶▶), stop execution (⏹), and restore the main window with one click (◉).
• Progress: Highlights the name of the currently executing task card in real-time, while fading the previous and next card names, giving you a clear view of the execution progress at a glance.
⚙ Settings
Open the system settings window (Shortcut: F12).
｛｝ Variables
Open the variable management window to configure global variables and local variables for the selected flow.
🔀 Flows
Open the flow management window to create, rename, or delete different task flows.
🤖 Models
Open the model management window to configure LLM API parameters for text translation and multimodal vision.
▶ Run Once / ▶▶ Run Current / ⏭ Run All
Run Once: Executes only the currently selected card once (useful for debugging).
Run Current: Executes all tasks in the currently active flow tab.
Run All: Executes all tasks across all flow tabs in sequence.
⏹ Stop All
Forcefully interrupts all currently running flows.
🖼 Image Preview / 👁 Live View / 📋 Log Output
Toggle the visibility of different panels at the bottom or sides.

Variable Manager

Accessed via the ｛｝ Variables button. Variables are used to dynamically store data or share states between multiple cards.

Variable Scope
Divided into Global Variables and Local Variables specific to a Flow. Local variables take precedence when names conflict.
Data Types
Currently supports Int (Integer), Double (Float), String, and Bool (Boolean).
How to Reference
Wherever cards support expressions, use @VariableName to read from or write/overwrite variables. Example: @Count = @Count + 1.

Flow Manager

Opened via the 🔀 Flows button. TaskFlow allows creating multiple flows within a project (vertical tabs on the left) to break down complex logic.

Basic Operations
Add new flows, rename, or delete. Note: Deleting a flow will also delete all task cards and local variables within it. This action cannot be undone.
Minimum Requirement
At least one flow must be kept. You can rename the last remaining flow, but cannot delete it.

Model Manager

Configure API endpoints required to call LLM (Large Language Model) services. Used for AI cards like LLM Translate or Multimodal Vision.

Configuration List
The model list is on the left. Model configurations take effect globally on the local machine (not just for the current project). Once configured, they can be reused across any project.
Core Parameters
API Endpoint: Full request address, e.g., https://api.deepseek.com/chat/completions or other OpenAI-compatible endpoints.
API Key: The Bearer Token provided by the service.
Model Name: The actual model name required by the backend, e.g., deepseek-chat or gpt-4o.
Test Connection
After configuration, click "Test Connection". The program will initiate a minimal chat request to verify API connectivity and key validity.

Settings & OCR

Configure software startup behaviors, task execution logic, and engine paths.

Startup Behavior
Supports setting: Auto start with Windows, auto load the last used project, run all flows immediately after startup, and hide the main window on startup (run entirely in the background). Essential for long-term unattended automation.
Execution & Loop
Flow Interval: Global delay added between the sequential execution of multiple cards.
Repeat Run All: When checked, after all flows finish running once, the app waits for a specified interval and reruns from the beginning, achieving infinite looping.
WeChat OCR Configuration
TaskFlow supports calling the extremely fast and highly accurate WeChat OCR engine component. Under OCR Settings, click Auto Detect. If WeChat has been logged in on the machine, it can usually auto-find the required file paths. Otherwise, manually specify WeChatOCR.exe and its corresponding WeChatXX.X.X runtime directory. Click "Test Availability" to verify.
General Tasks

Pause All Tasks General

Pauses flow execution for the specified number of milliseconds. Commonly used to wait for page loads, animations, etc.

Delay (ms)
Number of milliseconds to pause. Supports expressions. For example, 1000 pauses for 1 second.
📤 Output
No output (controls flow pause only)

Get Timestamp General

Gets the current system time and outputs a formatted string.

Format String
C# date format, e.g. yyyy-MM-dd HH:mm:ss, yyyyMMdd.
📤 Output
#N.text — Current time (formatted string based on the output format)

End Current Flow General

Immediately terminates execution of the current flow without affecting other flows.

📤 Output
No output (controls flow termination only)

End All Flows General

Immediately terminates execution of all flows.

📤 Output
No output (controls flow termination only)
Windows Operations

Win Launch App Windows

Launches a specified Windows application. You can specify launch arguments and working directory.

Application Path
Full path to the executable, e.g. C:\Windows\notepad.exe.
Launch Arguments
Optional command-line arguments passed to the application.
💡 Examples
App path C:\Program Files\Google\Chrome\Application\chrome.exe
Arguments https://www.google.com → Launches Chrome and opens the URL
Arguments --incognito https://www.google.com → Opens in incognito mode
📤 Output
No output (launches the application only)

Win Screenshot Windows

Captures a screenshot of a specified process window. Supports automatic grayscale conversion.

Process Name
Target window's process name without the .exe suffix. E.g. notepad, chrome.
Include Title Bar
Whether to include the window title bar area. Enabled by default. Uncheck to exclude the title bar region.
Top Crop Height
Custom pixel height to crop from the top of the window, useful for removing custom title bars. Default 0.
Convert to Grayscale
When checked, the screenshot is automatically converted to grayscale. Grayscale images reduce data size and improve processing speed and accuracy for template matching and OCR, while reducing color interference.
📤 Output
#N.image — Captured window image (color or grayscale)

Win Simulate Click Windows

Simulates a mouse click at specified coordinates within a process window (uses Windows message mechanism, does not move the actual mouse cursor).

X Coordinate Expression / Y Coordinate Expression
Coordinates within the window. Supports numbers, @variables, #task references, and expressions.
Click Type
Single Click: sends one click; Double Click: enables multiple clicks with customizable count and interval; Swipe: swipes from start to end coordinates with configurable duration.
Swipe Duration
Duration of the swipe operation (milliseconds), default 300ms. Only visible when click type is Swipe.
Background Click
When checked, sends background messages via PostMessage to the target process without requiring the window to be in the foreground. Requires specifying the target process name. Works when the window is occluded or minimized.
💡 Examples
Fixed coordinate click: X = 100, Y = 200
Reference template match output: X = {{#3.x}}, Y = {{#3.y}} (#3 is the template match card number)
Offset click: X = {{#3.x + 50}}, Y = {{#3.y - 10}}
📤 Output
#N.x — Actual click X coordinate
#N.y — Actual click Y coordinate

Win Close App Windows

Closes the application window with the specified process name.

Process Name
Name of the process to close.
📤 Output
No output (closes the application only)

Win UI Automation Windows

Uses the Windows UI Automation framework to operate UI elements. Can find controls by name or AutomationId and perform click, input, and other actions.

Process Name
Target window's process name.
Search By
By control Name or by AutomationId.
Match Mode
Exact match / Contains / Regular expression.
💡 Examples
Find button by name: Search By = Name, Match Mode = Contains, Search Text = OK
Find by AutomationId: Search By = AutomationId, Match Mode = Exact, Search Text = btnSubmit
Regex match: Match Mode = Regex, Search Text = ^(OK|Save)$ (matches controls named "OK" or "Save")
Regex wildcards: btn.*Submit (matches names starting with btn and ending with Submit), \d+ (matches names containing digits)
📤 Output
#N.text — Text content of the element (if applicable)

Win Simulate Input Windows

Simulates keyboard key presses or mouse wheel operations with modifier key combinations. Useful for automating shortcuts, scrolling pages, etc.

Modifier Keys
Optional modifier key combinations: None, Ctrl, Shift, Alt, Ctrl+Shift, Ctrl+Alt.
Input Action
Mouse Wheel Down: simulates scrolling down; Mouse Wheel Up: simulates scrolling up; Keyboard Key: simulates a specific key press.
Key Name
Only shown when input action is "Keyboard Key". Enter the key name, e.g. A, ENTER, TAB, ESCAPE, F5.
Scroll Amount
Only shown for mouse wheel actions. Default 120 (one standard scroll step).
Repeat Count
Total number of times to perform this action, default 1.
Repeat Interval (ms)
Wait time between each repetition, default 50ms.
💡 Examples
Ctrl+S Save: Modifier = Ctrl, Action = Keyboard Key, Key = S
Scroll down 5 times: Action = Mouse Wheel Down, Repeat = 5, Interval = 200
Press Enter: Modifier = None, Key = ENTER
📤 Output
#N.text — Description of the action performed

Win Subtitle Overlay Windows

Overlays subtitles on a specified process window. Useful for displaying translation results. Supports custom font, color, and background styles.

Display Text Expression
Text to display. Supports expressions. Can reference translation results like {{#5.text}}.
Target Window
When checked, subtitles are displayed on the specified process window; when unchecked, absolute screen coordinates are used.
Process Name
Target window for subtitle overlay (shown when "Target Window" is checked).
Select Display Region
Click to automatically capture the target process window, then select a rectangular region on the screenshot as the subtitle display area. Automatically fills in X/Y offset and width/height. Avoids manual coordinate calculation.
X / Y Offset
Offset relative to the target window's top-left corner. Can be automatically filled by region selection.
Subtitle Width / Height
Subtitle area dimensions. 0 = auto-fit to text.
Font Size / Font Color
Subtitle text size and color (hex, e.g. #000000). Color picker available for quick selection.
Background Style
Frosted Glass: semi-transparent acrylic effect; Solid Color: solid color fill; Transparent: no background; Auto Color Sample: automatically samples the average background color of the target area for a blended look.
Background Color
Color value with transparency, e.g. #80FFFFFF. Only shown in Frosted Glass/Solid Color modes. Color picker available.
Display Duration
Duration to show subtitles (milliseconds). 0 = persistent until next update.
Wait for subtitle to close before continuing
When checked, the flow waits until the subtitle display duration ends before executing the next task.
💡 Examples
Display static text: Subtitle content = Processing...
Display translation result: Subtitle content = {{#5.text}} (#5 is the LLM translation card)
Concatenate multiple variables: Subtitle content = Original: {{#3.text}} → Translation: {{#5.text}}
📤 Output
No output (displays subtitle overlay only)

Image Processing

Image Crop Image

Crops a specified region from the source image.

Source Image
Reference the output image from a preceding screenshot card, e.g. #1 (card number).
Crop Region X / Y / Width / Height
Top-left corner coordinates and dimensions of the crop rectangle. Supports expressions.
📤 Output
#N.image — Cropped image

Template Match Image

Searches for a template image within the source image. Supports single and multi-target matching.

Source Image
The target image to search in. Reference a preceding screenshot card.
Template Image
The small image to find. Loaded from file.
Match Threshold
Value between 0–1. Higher values require stricter matches. Typically set to 0.8–0.95.
Max Match Count
1 = single target match; >1 = multi-target match.
💡 Examples
Find button position: Threshold = 0.85, use If to check #N.result, then click at #N.x, #N.y
Multi-target match: Max count = 5, results accessible via OutputMatchResults array
Threshold guidelines: Identical icons 0.9–0.95, similar elements 0.75–0.85, fuzzy match 0.6–0.75
📤 Output
#N.image — Result image with match positions annotated
#N.result — Whether a match was found (true/false)
#N.x / #N.y — Center coordinates of the best match (single target)
OutputMatchScore — Best match score (0–1)
OutputMatchCount — Number of matches found
OutputMatchResults — Multi-target match result list (with X, Y, Score)

OCR Recognition Image

Performs optical character recognition (OCR) on an image. Supports PaddleOCR and WeChat OCR engines.

Source Image
Reference the output image from a preceding screenshot or crop card.
OCR Engine
PaddleOCR (built-in) or WeChatOCR (requires WeChat installation, configure path in Settings).
Check Contains Text
Optional. When checked, detects whether the recognition result contains the specified string.
Target Text
Text to check for (shown when "Check Contains Text" is checked).
Mask Image
Optional. Black-and-white binary image: white regions are kept, black regions are masked out. Used to exclude unwanted areas.
ROI Region (X/Y/Width/Height)
Optional. Limits the recognition area. The image is cropped before OCR.
💡 Examples
Basic OCR: Screenshot → Crop ROI → OCR → Get #N.text
With check: Enable "Check Contains Text", Target = Success, If branch on #N.result
Improve accuracy: Preprocess image (grayscale + binarize) before OCR
📤 Output
#N.text — Full OCR recognized text
#N.result — Whether the specified text was found (when check is enabled)

Color Detection Image

Detects the proportion of pixels within a specified HSV color range in the image to determine if the target color exists.

Source Image
Reference the output from a preceding screenshot or image processing card.
HSV Lower / Upper Bound
HSV color space range (H: 0–180, S: 0–255, V: 0–255).
ROI Region (X/Y/Width/Height)
Optional. Limits the detection area.
💡 Examples
Detect red area: H lower = 0 upper = 10, S lower = 100 upper = 255, V lower = 100 upper = 255
Detect green area: H lower = 35 upper = 85
HSV hue reference: Red 0–10/170–180, Orange 10–25, Yellow 25–35, Green 35–85, Blue 85–125, Purple 125–170
📤 Output
#N.image — Color detection visualization image
#N.result — Whether color match meets threshold (true/false)
OutputMeanH/S/V — Average HSV values in the region
OutputMatchRatio — Matching pixel ratio (0–1)

Color Segmentation Image

Segments the image by HSV color range, keeping matching pixels and setting the rest to black. Commonly used to extract specific color regions for subsequent OCR.

HSV Lower / Upper Bound
HSV color range for pixels to keep.
📤 Output
#N.image — Color-segmented image (only matching regions retained)

Image Preprocess Image

Applies grayscale conversion, binarization, dilation, erosion, and other preprocessing operations to improve accuracy of subsequent OCR or template matching.

Source Image
Reference the output from a preceding screenshot or image processing card.
Grayscale Conversion
Whether to convert the color image to grayscale. Enabled by default.
Binarization Method
Binary: fixed threshold binarization; BinaryInv: inverse binarization; Otsu: automatic threshold (Otsu's method); Triangle: triangle method auto threshold; Disabled: skip binarization.
Binarization Threshold
Only used with Binary/BinaryInv, default 128. Pixels brighter than the threshold become white, others become black.
Morphological Operation
Opening: erode then dilate, removes noise; Closing: dilate then erode, fills holes; Dilation: expands white regions; Erosion: shrinks white regions; Disabled: skip.
Morphological Kernel Size
Kernel size for morphological operations, default 3. Larger kernels produce more pronounced effects.
📤 Output
#N.image — Preprocessed image

Blob Analysis Image

Performs connected component analysis on binary images to find all independent blobs.

Source Image
Reference the output from a preceding binarization or color segmentation card.
Area Range
Min and max blob area filter, default 100–999999.
Sort Method
By area descending / ascending / left to right / top to bottom.
Max Return Count
Maximum number of blobs to return, default 10.
Polarity Invert
true = detect dark blobs, false = detect bright blobs.
Mask Image
Optional. Black-and-white binary image: white regions are kept, black regions are masked out.
ROI Region (X/Y/Width/Height)
Optional. Limits the analysis area. The image is cropped before analysis.
💡 Examples
Typical pipeline: Screenshot → Color segmentation/binarization → Blob analysis → Get target position
Filter small noise: Min area = 500, ignore blobs that are too small
Find largest target: Sort = Area descending, Max count = 1
📤 Output
#N.image — Result image with blob positions annotated
#N.result — Whether blobs were detected (true/false)
#N.x / #N.y — Center coordinates of the first blob
OutputBlobCount — Number of blobs detected
OutputBlobResults — Blob list (with X, Y, Width, Height, Area)

Image Resize Image

Resizes the image to specified target dimensions.

Target Width / Height
Image dimensions after resizing (pixels).
📤 Output
#N.image — Resized image
OutputScaleRatio — Actual scale ratio
Data Processing

Expression Eval Data

Evaluates mathematical or logical expressions.

Expression
Supports + - * / % arithmetic, and > < == != comparisons. Can reference other card outputs, e.g. #1.text, #2.x.
💡 Examples
Math calculation: #1.x * 2 + 100 → doubles the coordinate and offsets by 100
String comparison: #3.text == "Success" → checks if OCR result matches specific text
Numeric comparison: #2.x > 500 → checks if coordinate is in the right half
Combined condition: #1.result == true → use with If branches
📤 Output
#N.text — Expression evaluation result (string)
#N.result — Boolean result (when expression is a comparison)

String Substring Data

Extracts a substring from a string.

Text Source
Reference another task card's text output, or manually enter text.
Start Position Mode
Manual: directly specify the start index (0-based); Find Character: locate the start position by searching for a specific character.
Manual Start Position
Start index for extraction (0-based). Only shown in manual mode.
Find Character
Character used to locate the start position. Only shown in find mode.
Find Offset
Offset after finding the character. Only shown in find mode.
Extraction Length
Number of characters to extract. -1 extracts to the end.
📤 Output
#N.text — Extracted substring

Type Convert Data

Converts a string to an integer. Supports referencing other tasks' text outputs or variables.

Text Source
Reference another task card's text output, or manually enter an expression.
Input Expression
Text to convert. Supports @variables and #task references.
📤 Output
#N.text — Converted value (string form)
#N.result — Converted integer value

Array Parse Data

Extracts an element by index from an array-format string. Supports coordinate arrays, string arrays, etc.

Array Type
Integer / String / Coordinate / Double.
Index
Element index to extract (0-based). Supports expressions.
💡 Examples
Extract 2nd coordinate from Blob results: Array Type = Coordinate, Index = 1
Dynamic index: Index = {{#5.loopIndex}} (sequentially extract each element in a For loop)
📤 Output
#N.text — Extracted element value (string form)
#N.x / #N.y — Coordinate values (for coordinate array type)
AI Operations

LLM Translate AI

Uses a Large Language Model (LLM) to translate text. Requires configuring an API key in "Model Management" first.

Translation Model
LLM model configured in Model Management.
Source Text
Text to translate. Supports expression references to OCR results, e.g. {{#4.text}}.
Target Language
Translation target language, default "Chinese".
System Prompt
Custom translation instructions. Can be modified to adjust translation style. Supports {target language} placeholder.
💡 Examples
Translate OCR result: Source text = {{#4.text}}, Target language = Chinese (#4 is the OCR card)
Real-time translation pipeline: Screenshot → Crop subtitle area → OCR → LLM Translate → Subtitle display
📤 Output
#N.text — Translated text

Multimodal Vision AI

Uses a vision-capable Large Language Model to analyze image content. Can be used for image description, content understanding, etc.

Model
Multimodal LLM model configured in Model Management.
Prompt
Instructions telling the model how to analyze the image. Supports @variables and #task references.
System Prompt
Custom analysis instructions. Can be modified to adjust response style.
Source Image
Reference the output from a preceding screenshot or image processing card.
💡 Examples
Image description: Prompt = Describe the main content in the image
Status check: Prompt = Is the button in the image enabled? Answer only "yes" or "no", use with If branch
Extract information: Prompt = Extract all numbers in the image, separated by commas
📤 Output
#N.text — Model analysis result text
#N.result — Whether analysis was successful (true/false)
Control Flow

If-Else Branch Control Flow

Executes different branches based on a condition. Supports multiple Elif branches and an optional Else branch.

Condition Source
Manually enter an expression or reference another card's execution result (Result).
Condition Expression
An expression that returns a boolean, e.g. #1.result == true.
💡 Examples
Check template match result: Source = TaskResult, reference the template match card → If branch on success, Else on failure
Manual condition: Source = ManualInput, Expression = #3.text == "Confirm"
Multi-condition branching: If + Elif + Else for three-way or more branch logic
📤 Output
No direct output (controls execution path)

Tip: Right-click the IF start card to add Elif branches or show/hide the Else branch. The collapse button (▶) can fold the entire branch block.

For Loop Control Flow

Repeats execution of task cards inside the loop body a specified number of times.

Loop Count
Total number of iterations. Supports expressions.
💡 Examples
Fixed loop: Count = 10 → repeats 10 times
Iterate Blob results: Count = {{#5.blobCount}}, use Array Parse + index {{#N.loopIndex}} inside the loop to process each item
With Break: use If inside the loop to check a condition and break when met
📤 Output
#N.loopIndex — Current loop index (starts from 0)

Tip: Inside the loop body you can use #N.loopIndex to reference the current loop index (N is the loop start card's number).

Break Loop Control Flow

Immediately exits the nearest For loop and continues executing tasks after the loop. Typically used with an If condition.

📤 Output
No output (controls loop exit only)
